    Security
    
          
    
            
    App lock
    
            
    
              
              
            
    
          
    
          
    
            
    Two-factor (authenticator app)
    
            
    
              
              
            
    
          
    
          
    
            
          
    
          
    Only a salted hash is stored (PBKDF2-SHA256, 600,000 rounds) in etc/secrets/app-lock.json, readable by your user account only. The lock guards this window and its commands; to protect the files themselves on a lost laptop, turn on disk encryption (BitLocker, FileVault or LUKS) and a login password.

    Storage
    
          
    What the Veranda folder holds. Free space removes debug builds, test suites and static libraries from installed packages, gzips old SQL backups, deletes leftover downloads and trims oversized logs. Databases, projects and settings are never touched.
    
          
    
          
    
            
            
          
    
          
    
        
    
        
    
          
    Modules
    
          
    Veranda is a local web workbench: the server stack is always there; the rest can be switched off to keep the window plain. Nothing is uninstalled, the pages are only hidden.
    
          
    
            
            
            
          
    
        
    
        
    
          
    Move to another computer
    
          
    Pack your Veranda setup, projects, SSH and git keys, VS Code and Claude Code settings into one password-protected file. On the new computer (Linux, Windows or macOS) restore it with Veranda; packages, repositories and extensions are installed again there.

    Enable two-factor
    
    
    
      
    Adds a 6-digit code from an authenticator app (Aegis, Google Authenticator, Authy, 1Password, Bitwarden…) after your PIN or password. Confirm with your current PIN or password first.
    
      
    
    
    
    
      
    In the app choose "enter a setup key" and type this key (or paste the link below into an app that accepts it):
    
      
    
      
    
      
      
    Type the code the app shows now. The second factor is only switched on once a code matches.
    
    
    
    
    
      
    Turn the second factor off: from then on the PIN or password alone unlocks Veranda.
